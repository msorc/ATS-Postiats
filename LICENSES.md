# Licenses of ATS/Postiats

This file summarizes which license applies to which part of the repository.
The license texts are the files named below. Where a source file carries its
own license header, read it together with this summary (see "Source headers").

## Overview

| Directory | License | License file |
|-----------|---------|--------------|
| `src/` (the compiler `patsopt`) | GPLv3 | [COPYING-gpl-3.0.txt](COPYING-gpl-3.0.txt) (`COPYING` is a symlink to it) |
| `utils/` (tools built on the compiler) | GPLv3 | [COPYING-gpl-3.0.txt](COPYING-gpl-3.0.txt) |
| `prelude/`, `libats/` (ATSLIB: the ATS source of the libraries; except the arena library `libats/*/arena.*`, which is MIT, see "Files under MIT inside the GPL/LGPL directories") | LGPLv3, with the linking exception below | [COPYING-lgpl-3.0.txt](COPYING-lgpl-3.0.txt) |
| `ccomp/runtime/` (C runtime headers) | see "Source headers" | headers say GPLv3; README also announces an MIT-style release of the C headers (`doc/DISTRIB/ATS-Postiats-include/COPYING`) |
| `contrib/` | MIT | [contrib/LICENSE](contrib/LICENSE) |
| `COPYING-lgpl-2.1.txt` | LGPLv2.1 text, kept for the `contrib/` and `libatsdoc/` files whose headers say "version 2.1" | [COPYING-lgpl-2.1.txt](COPYING-lgpl-2.1.txt) |

## Linking exception

This is the exception stated in `README.md`, reproduced verbatim:

> As a special exception, any C code generated by the Compiler based on the Libraries
> source is not considered by default to be licensed under GPLv3/LGPLv3. If you use such
> C code together with other code to create an executable, then the C code by itself does
> not cause the executable to be covered by GPLv3/LGPLv3. However, there may be reasons
> unrelated to using ATS that can result in the executable being covered by GPLv3/LGPLv3.

It is not part of any of the license texts above; it is a statement of the project.

## Files under MIT inside the GPL/LGPL directories

Some files in the GPL/LGPL directories above were written by Mikhail Sorochan
and are under the MIT license. They carry the lines
`SPDX-FileCopyrightText: 2026 Mikhail Sorochan` and
`SPDX-License-Identifier: MIT` at the top. They are: the arena library
(`libats/SATS/arena.sats`, `libats/DATS/arena.dats`, `libats/CATS/arena.cats`),
`utils/arenagen`, the arena specs (`src/*.spec` and the other `*.spec` files),
the bootstrap scripts `src/CBOOT`, the `doc/EXAMPLE/LINHEAP` tests, and the
other files listed by `grep -rl "SPDX-License-Identifier: MIT"`. For such a
file the SPDX line is authoritative, whatever the directory's license is.

## Source headers

The designations above come from the README. The headers inside the source
files do not always agree with them. Counts of tracked files whose first 4000
bytes contain the notice (a survey, not a legal audit):

| Directory | GPL notice | LGPL notice | MIT / permissive notice |
|-----------|-----------:|------------:|------------------------:|
| `src/` | 277 | 0 | 0 |
| `prelude/` | 221 | 0 | 0 |
| `libats/` | 173 | 0 | 0 |
| `ccomp/runtime/` | 14 | 0 | 0 |
| `utils/` | 55 | 3 (2.1) | 7 |
| `libatsdoc/` | 0 | 7 (2.1) | 0 |
| `contrib/` | 54 | 36 (2.1) | 75 |

In particular, the README designates the libraries (`prelude/`, `libats/`) as
LGPLv3, while their source headers still carry the GPLv3 notice inherited from
upstream. The same holds for the C runtime headers in `ccomp/runtime/`. Some
`contrib/` packages (for example the libcurl, hiredis, jansson and z3 bindings
in `contrib/atscntrb/`) carry LGPLv2.1 or GPLv3 headers rather than MIT.
Reconciling these is a decision for the copyright holder; until then, the
header of an individual file is the most specific statement for that file.
