# utils/atsopt

The manual of the ATS2 compiler `patsopt` (`atsoptman.atxt`): the
document is written in the `.atxt` format and is processed by `atsdoc`
(see `utils/atsdoc`).

    cd utils/atsopt/DOCUGEN && make -f Makefile all

(the `DOCUGEN` directory is the one of the documents of ATS2: the
`Makefile` of it is generated from `Makefile.atxt`).
