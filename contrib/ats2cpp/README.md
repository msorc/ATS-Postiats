# contrib/ats2cpp

The C++ mode of the C backend of ATS2: the code that the compiler emits
is C++ instead of C.

The directory holds the headers and the libraries that the C++ code
needs (the `ccomp` and `libats` directories are the C++ versions of the
ones of the compiler) and the `TEST` directory.

The directory is part of the release tarball (`doc/DISTRIB`).
