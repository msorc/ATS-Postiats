# doc/EXAMPLE/MISC

Miscellaneous examples of ATS2: the coin-flip problem, the ferryman
problem, the Fibonacci numbers (by loop and by tail recursion), the
continuation-passing-style square root of an integer, and so on.

    cd doc/EXAMPLE/MISC && make -f Makefile all

The directory is part of the regression suite (`doc/Makefile_test`) and it
is shipped in the release tarball (`doc/DISTRIB`).
