# doc/EXAMPLE/INTRO

The introductory examples of ATS2: the Ackermann function, the reverse of
a list, the conversion between strings and numbers, binary trees, and so
on. They are the code of the first chapters of the ATS2 tutorial.

    cd doc/EXAMPLE/INTRO && make -f Makefile all

The directory is part of the regression suite (`doc/Makefile_test`) and it
is shipped in the release tarball (`doc/DISTRIB`).
