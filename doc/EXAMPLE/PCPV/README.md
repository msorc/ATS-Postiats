# doc/EXAMPLE/PCPV

Examples that use the *Programming in the Presence of Variance* (PCPV)
interface of ATS2: the search of an array, and so on.

    cd doc/EXAMPLE/PCPV && make -f Makefile all

The directory is part of the regression suite (`doc/Makefile_test`) and it
is shipped in the release tarball (`doc/DISTRIB`).
