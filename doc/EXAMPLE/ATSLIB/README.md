# doc/EXAMPLE/ATSLIB

Examples that use the ATS2 standard libraries (`prelude/` and `libats/`):
bit vectors, deques, dynamic arrays, hash tables, the POSIX directory
API, and so on.

    cd doc/EXAMPLE/ATSLIB && make -f Makefile all

The directory is part of the regression suite (`doc/Makefile_test`) and it
is shipped in the release tarball (`doc/DISTRIB`).
