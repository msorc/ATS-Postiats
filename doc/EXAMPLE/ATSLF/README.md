# doc/EXAMPLE/ATSLF

Examples that use the ATS2 theorem prover (the linear-logic based proof
checking of the propositions): the Ackermann function, the lemmas about
binary trees, Hilbert's calculus, the infinitude of primes, and so on.

    cd doc/EXAMPLE/ATSLF && make -f Makefile all

The directory is part of the regression suite (`doc/Makefile_test`).
