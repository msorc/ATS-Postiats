ats2-postiats-0.4.3: 



This is the 54th release of ATS2, the successor of the ATS programming
language. The compiler for ATS2 is given the name ATS/Postiats or simply
Postiats.

This release is a line of ATS2 that follows 0.4.2 and removes the garbage
collector: heap memory is managed by linear types only. The compiler is
now written in ATS2 and compiles itself; ATS1 is not needed for anything.

ATS-Postiats is hosted at github:

https://github.com/msorc/ATS-Postiats

The releases are published there (Releases), with a .sha256 file for each
tarball. The upstream project (ATS2 0.4.2 and earlier) is at:

https://github.com/githwxi/ATS-Postiats

How to build and install: INSTALL. How to move code from 0.4.2:
doc/GUIDE/migrating-from-0.4.2.md. The messages of the compiler:
doc/GUIDE/faq.md.

BREAKING CHANGES

1. There is no garbage collector. The Boehm-GC runtime
   (ATS_MEMALLOC_GCBDW), the --gc/--gcbdw options of myatscc and the GC
   detection of mytempacc are gone. libc malloc is the allocator.
2. The compiler always rejects nonlinear heap allocation (there is no
   opt-out flag):
   - a datatype with a non-nullary constructor (enum-like datatypes
     are still allowed; use datavtype otherwise);
   - a cloref closure (use a function, a linear closure cloptr/llam,
     or a flat closure lam@);
   - a boxed tuple or record, linear ones included (a box could never
     be freed): '( ), '{ }, $tup(_vt), $rec(_vt); use flat ones;
   - $delay (use $ldelay and stream_vt) and $list_t;
   $list/$lst now yield a list_vt.
   See doc/EXAMPLE/LINHEAP for a test of each rule.
3. The prelude and libats are rewritten accordingly: list, option,
   stream, lazy, arrayref, matrixref and the nonlinear libats modules
   (libats/ML, fun* containers, gflist) are removed; ref is kept but
   can only be made from memory that is never freed (ref_make_viewptr).
   libats/BUCS320, BUCS520, ATS1 and ATS2 are dropped, and so are
   the BUCS320 copies in the contrib/libatscc* runtime libraries.
4. Programs that compiled with 0.4.2 and use any of the above need to be
   changed: see the migration guide (doc/GUIDE/migrating-from-0.4.2.md),
   which has the before and after of every construct, and the FAQ
   (doc/GUIDE/faq.md), which lists the compiler's messages.

NEW

5. The compiler (src/) is written in ATS2 and compiles itself (stage 2 and
   stage 3 are bit-for-bit identical). The sources were ported from ATS1
   (notes: src/PORTING.md; the ATS1 sources are in the git history) and
   the result is output-identical to the ATS1 build.
6. A clone builds with a C compiler, make, python3 and libgmp (or none,
   with KIND=intknd): `make` builds the compiler from the bootstrap C
   bundle src/CBOOT, which is tracked in git. No ATS compiler is needed.
   Other stage-0 compilers are still possible (make PATSOPT=..
   STAGE0HOME=..).
7. New root Makefile targets: all, bootstrap, tools (atsdoc, pats2xhtml),
   check, test, install and uninstall (PREFIX, DESTDIR; the wrapper
   scripts of PREFIX/bin set PATSHOME), dist (the tarballs and their
   .sha256), distclean, doc, book.
8. One release tarball, ATS2-Postiats-.tgz, replaces the -gmp and
   -int variants: `./configure [--prefix=..] [--without-gmp] && make &&
   make install` uses libgmp when  is there. INSTALL is the one
   document of the build and installation.
9. The C flags that every user passed by hand are defaults:
   -DATS_MEMALLOC_LIBC is no longer needed (libc is the allocator unless
   -DATS_MEMALLOC_USER or -DATS_MEMALLOC_UNDEF is given; the flag is still
   accepted), alloca.h is included by the C run-time (no -include alloca.h),
   and patscc runs ${CC:-cc} (the environment variable CC, else cc) with
   -std=c99 -D_GNU_SOURCE (PATSCCOMP still overrides the whole command). The
   makefiles of src/ detect STAGE0HOME (from the directory of PATSOPT) and
   C3NSTRINTKND (gmpknd if  is found, else intknd). So
   `patscc -o hello hello.dats` needs no flags.
10. libats/arena (arenas and the global arena, with glist/gopt) and
    utils/arenagen, which generates the arena encoding of algebraic
    types for compiler-like code.
11. Documentation: README.md, INSTALL, doc/GUIDE (quickstart, migration
    guide, FAQ, architecture of the compiler), READMEs for the INTRO and
    LINHEAP examples, manual pages for patsopt, patscc and myatscc
    (installed in PREFIX/share/man/man1), SECURITY.md, CONTRIBUTING.md and
    the code of conduct. The books INT2PROGINATS and ATS2TUTORIAL are
    rewritten for the linear-only dialect.
12. All ATS2 tools are rewritten in linear style: patscc, myatscc,
    tempacc, atexting, atsreloc, atslex, libatsrec, CATS-parsemit, the
    atscc2js compiler (on the global arena) and its libatscc2js runtime
    library, ATS-extsolve(-z3/-smt2), and the atscntrb/npm-utils packages.
13. pats2xhtml and libatsynmark (utils/atsynmark, utils/libatsynmark) and
    atsdoc and libatsdoc (the .atxt text processor and its run-time library)
    are ported to ATS2 (no GC) and built without ATS1, and so are the .atxt
    templates of the repository: the text that they generate is identical
    to the one of the ATS1 toolchain. `make -f codegen/Makefile_atslib`
    regenerates the prelude sources with the new atsdoc.

REMOVED

14. GC-only examples and experimental packages in doc/ and npm-utils/.
15. Only the C, C++ and JavaScript backends are kept. The transpilers
    atscc2clj, atscc2erl, atscc2php, atscc2pl, atscc2py3, atscc2r34 and
    atscc2scm, along with their runtime libraries libatscc2clj,
    libatscc2erl, libatscc2php, libatscc2pl, libatscc2py3, libatscc2r34 and
    libatscc2scm, are removed. What is kept: the C backend (src/pats_ccomp*),
    its C++ mode (contrib/ats2cpp) and the JavaScript backend
    (contrib/CATS-atscc2js and contrib/libatscc2js, with the shared
    contrib/CATS-parsemit and contrib/libatscc).
16. SourceForge is no longer the distribution channel; the tarballs are
    GitHub Releases.

MIGRATION

17. Read doc/GUIDE/migrating-from-0.4.2.md. In short: list/list0 become
    list_vt, option become option_vt, datatype becomes datavtype, cloref
    becomes cloptr or lam@, $delay becomes $ldelay (stream_vt), arrayref
    becomes arrayptr, libats/ML becomes the linear containers of libats,
    and boxed tuples and records become flat ones. Drop -DATS_MEMALLOC_GCBDW
    and -lgc from your build.
