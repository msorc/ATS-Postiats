ats2-postiats-0.4.3: 



This is the 54th release of ATS2, the successor of the
ATS programming language. The compiler for ATS2 is given
the name ATS/Positats, ATS2/Postiats or simply Postiats.

The official website for ATS is:

http://www.ats-lang.org

ATS-Postiats is hosted at github:

https://github.com/githwxi/ATS-Postiats

Major releases of ATS2 are available at:

https://sourceforge.net/projects/ats2-lang/

Major releases of external packages for ATS2 are available at:

https://sourceforge.net/projects/ats2-lang-contrib/

Here is a list of major additions and changes since the last release:

0. The compiler (src/) is now written in ATS2 and compiles itself: ATS1 is
   no longer required to build ATS2. The sources were ported from ATS1 (notes:
   src/PORTING.md; the ATS1 sources are in the git history) and the result is
   bit-for-bit self-hosting (stage 2 and stage 3 are identical) and
   output-identical to the ATS1 build. The first patsopt is any ATS2 compiler
   (make -C src PATSOPT=.. [STAGE0HOME=..]) or the C bundle generated by
   `make -C src CBOOT` (src/CBOOT, needs only a C compiler and libgmp). The
   generated prelude sources (prelude/*/CODEGEN) are now kept in git. Build,
   bootstrap and test instructions: README, CLAUDE.md, src/README.
1. GC support is removed: heap memory is managed through linear types
   and views only. The Boehm-GC runtime (ATS_MEMALLOC_GCBDW) is gone,
   along with the --gc/--gcbdw options of myatscc and the GC detection
   of mytempacc.
2. The compiler always rejects nonlinear heap allocation (there is no
   opt-out flag):
   - a datatype with a non-nullary constructor (enum-like datatypes
     are still allowed; use datavtype otherwise);
   - a cloref closure (use a function, a linear closure cloptr/llam,
     or a flat closure lam@);
   - a boxed tuple or record, linear ones included (a box could never
     be freed): '( ), '{ }, $tup(_vt), $rec(_vt); use flat ones;
   - $delay (use $ldelay and stream_vt) and $list_t;
   $list/$lst now yield a list_vt.
   See doc/EXAMPLE/LINHEAP for a test of each rule.
3. The prelude and libats are rewritten accordingly: list, option,
   stream, lazy, arrayref, matrixref and the nonlinear libats modules
   (libats/ML, fun* containers, gflist) are removed; ref is kept but
   can only be made from memory that is never freed (ref_make_viewptr).
   libats/BUCS320, BUCS520, ATS1 and ATS2 are dropped, and so are
   the BUCS320 copies in the contrib/libatscc* runtime libraries.
4. New: libats/arena (arenas and the global arena, with glist/gopt) and
   utils/arenagen, which generates the arena encoding of algebraic
   types for compiler-like code.
5. All ATS2 tools are rewritten in linear style: patscc, myatscc,
   tempacc, atexting, atsreloc, atslex, libatsrec, CATS-parsemit, the
   atscc2js compiler (on the global arena) and its libatscc2js runtime
   library, ATS-extsolve(-z3/-smt2), and
   the atscntrb/npm-utils packages. GC-only examples and experimental
   packages are removed from doc/ and npm-utils/.
6. pats2xhtml and libatsynmark (utils/atsynmark, utils/libatsynmark) are
   ported to ATS2 (no GC) on the new compiler modules and built without ATS1
   (make -C utils/atsynmark); their output is identical to the ATS1 build.
7. atsdoc and libatsdoc (the .atxt text processor and its run-time library) are
   ported to ATS2 (no GC), and so are the .atxt templates of the repository
   (the 991 code blocks of 411 files and their helper files: main0, glist,
   utils/atsdoc/HATS/atsdoc_compat.hats): the text that they generate is
   identical to the one of the ATS1 toolchain (369 of 415 templates, 22 differ
   in the lines of the generated Makefiles that name the compiler, 24 cannot
   be run by either toolchain), and ATS1 is no longer needed for anything.
   `make -f codegen/Makefile_atslib` regenerates the prelude sources with the new
   atsdoc, `make -C utils/atsdoc genall` regenerates and checks all the templates,
   `make -C doc/DISTRIB atspackaging` and `atspacktarzvcf_gmp` work again.
8. Only the C, C++ and Javascript (JS) backends are kept: the transpilers
   atscc2clj, atscc2erl, atscc2php, atscc2pl, atscc2py3, atscc2r34 and
   atscc2scm, along with their runtime libraries libatscc2clj, libatscc2erl,
   libatscc2php, libatscc2pl, libatscc2py3, libatscc2r34 and libatscc2scm,
   are removed.  What is kept: the C backend (src/pats_ccomp*), its C++ mode
   (contrib/ats2cpp) and the Javascript backend (contrib/CATS-atscc2js and
   contrib/libatscc2js, with the shared contrib/CATS-parsemit and
    contrib/libatscc).
9. The C flags that every user passed by hand are defaults now:
   -DATS_MEMALLOC_LIBC is no longer needed (libc is the allocator unless
   -DATS_MEMALLOC_USER or -DATS_MEMALLOC_UNDEF is given; the flag is still
   accepted), alloca.h is included by the C run-time (no -include alloca.h),
   and patscc runs ${CC:-cc} (the environment variable CC, else cc) with
   -std=c99 -D_GNU_SOURCE (PATSCCOMP still overrides the whole command). The
   makefiles of src/ detect STAGE0HOME (from the directory of PATSOPT) and
   C3NSTRINTKND (gmpknd if  is found, else intknd), and Makefile_devl
   uses nproc for JOBS. So `patscc -o hello hello.dats` needs no flags.

Please note that in this release, there are two variants of
the package released: The "gmp" variant depends on the GMP library and
the "int" variant does not depend on the GMP library.
