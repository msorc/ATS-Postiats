# Some key steps in releasing ATS
#
######

# HX-2026-10-21:

###### beg of [how-to-release.txt] ######

#
# step 0:
#

Please do tagging immediately before or after the release
of a new ATS2 package

git tag -a <version> -m"Tagging immediately before releasing ..."
git tag -a <version-aft> -m"Tagging immediately after releasing ..."
git push --tags

#
# step 1:
#

Update ${PATSHOME}/VERSION, the version of
${PATSHOME}/doc/DISTRIB/ATS-Postiats/configure.ac, the version macros of
${PATSHOME}/src/pats_basics.sats and the changelog ${PATSHOME}/CHANGES-ats2.

Check that all of them agree:

sh ${PATSHOME}/share/SCRIPT/check_release_version.sh

#
# step 2:
#

cd ${PATSHOME}
make -f Makefile_devl PATSOPT=<stage-0 patsopt> all
make -f Makefile_devl bin_atsdoc
(cd src && make CBOOT)

#
# step 3:
#

cd ${PATSHOME}
cd doc/DISTRIB
#
# Update [Makefile.atxt] with
# the current version number of ATS
# Then do 'make -f Makefile.gen'
#
make atspackaging
make atspacktarzvcf # for ATS2-Postiats-xxx.tgz (one tarball: ./configure --without-gmp for the intknd kind)
#
make atscontribing
make atscontribtarzvcf # for ATS2-Postiats-contrib-xxx.tgz
#
# Update [Makefile_inclats] with
# the current version number of ATS
#
make -f Makefile_inclats
make -f Makefile_inclats tarzvcf # ATS2-Postiats-include-xxx.tgz
#
# step 4:
#

Generate the release notes from the changelog:

sh ${PATSHOME}/share/SCRIPT/make_release_notes.sh <version>

#
###### end of [how-to-release.txt] ######
