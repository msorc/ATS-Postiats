# LECTURE/MYLIB

The library of the book (the combinators on integers, lists, arrays and
streams) is built by the lectures themselves, in the `.hats` files of their
`CODE` directories: `04/CODE/intfun.hats`, `05/CODE/listfun.hats`,
`06/CODE/listfun2.hats`, `07/CODE/listfun3.hats`, `08/CODE/arrayfun.hats`,
`10/CODE/streamfun.hats`, `11/CODE/streamfun2.hats`.

The directory `DOCUGEN` is the generator of the documentation of the library of
the GC era (functional lists `list0`, `cfun`, `libats/ML`, ...), which is no longer
available in the linear-only dialect: it is kept for reference only and it
does not build any more.
