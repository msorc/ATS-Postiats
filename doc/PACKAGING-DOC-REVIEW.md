# ATS-Postiats: packaging & documentation review

Written 2026-10-21, against `master` at `874606266` (4169 tracked files).
Scope: project structure, documentation, and the build/packaging process.
This is **not** a code review — the ATS2 sources themselves were not assessed.

Every claim below was verified by running the relevant command in the working
tree; the evidence is quoted so it can be re-checked.

---

## Summary

The compiler and the no-GC port are in good shape: the self-hosting build, the
`patsopt` / `atsdoc` / `libatsynmark` tools, the md5 regression suites, and
`src/PORTING.md` are coherent and well documented.

The problems are concentrated in two places:

1. **The release/packaging machinery** (`doc/DISTRIB/`, `nix/`,
   `share/SCRIPT/`) has accumulated references to trees and make targets that
   no longer exist. It currently **cannot produce a tarball** (see A1, A2, A3).
2. **The prose documents** (the books, `INSTALL`, `doc/DISTRIB/README`) still
   describe the ATS1/GC-era system, so a reader following them is misled.

Fixing A1–A6 unblocks the release. B7–B13 stop the docs from actively
misleading. The rest is hygiene.

**Priority order:** D1 (do first) → D2 (documentation accuracy) → D3 (build
process) → D4 (structure) → D5 (worth doing, cheap).

---

## A. Build & packaging: things that are actually broken

These are not style opinions — each one breaks a documented command.

### A1. The release version gate fails today

`VERSION` is `0.4.3`; `doc/DISTRIB/ATS-Postiats/configure.ac` still says
`0.4.2`. `share/SCRIPT/build_release.sh:check_ac_init_version` compares them
and `exit 1`s.

```
$ PATSVERSION=$(cat VERSION)
$ grep -Fxq "AC_INIT([ATS2/Postiats], [$PATSVERSION], [gmpostiats@gmail.com])" \
      doc/DISTRIB/ATS-Postiats/configure.ac && echo PASS || echo FAIL
FAIL (release script would exit 1)
```

`CHANGES-ats2` also has no `0.4.3` section (only `CHANGES-contrib` does), and
`doc/DISTRIB/ATS-Postiats/RELEASE/` has release notes only through `0.4.2`.
The 0.4.3 release is half-declared: the version was bumped in two places, the
changelog and `configure.ac` were left behind.

### A2. The `include` tarball cannot be built

`doc/DISTRIB/Makefile_inclats:46` copies `$(SRC)/libats/ML/CATS/*.cats`.
`libats/ML` was deleted in the no-GC port. Reproduced:

```
cp: cannot stat 'ATS-Postiats/libats/ML/CATS/*.cats': No such file or directory
make: *** [Makefile_inclats:45: update] Error 1
```

The same dead path is in `.gitignore` (lines 240–243) and in
`doc/DISTRIB/ATS-Postiats/libats/ML/**` (14 `.keeper` files) — the skeleton
still reserves directories for a library that no longer exists.

### A3. `nix/tarball.nix` calls a target that does not exist

`make -C doc/DISTRIB atspacktarzvcf` — the target was split into
`atspacktarzvcf_gmp` / `atspacktarzvcf_int`, and the bare name was commented
out in `Makefile.atxt:396-397`.

```
$ make -n atspacktarzvcf
make: *** No rule to make target 'atspacktarzvcf'.  Stop.
```

`nix/build.nix` is worse: it has no `buildPhase` and sets `src = tarball`
where `tarball` is a derivation, not a path. `nix/default.nix` uses
`import <nixpkgs>` while `flake.nix` pins a nixpkgs rev — two divergent nix
entry points, and the flake just re-exports `pkgs.ats2` rather than building
this tree (the TODO at `flake.nix:15` says so).

### A4. `docugen/Makefile_atslib` references the removed `libats/ML`

```
$ make -n -f docugen/Makefile_atslib all
  make -C "."/libats/ML/SATS/DOCUGEN -f Makefile.gen
```

`libats/ML` does not exist. `codegen/Makefile_atslib` (the one `AGENTS.md`
points at) is fine.

### A5. `make` at the repository root does not work

There is no root `Makefile`; only `Makefile_devl`.

```
$ make
make: *** No targets specified and no makefile found.  Stop.
```

Every document says `make -f Makefile_devl …`, a name that signals
"temporary workaround" to a newcomer.

### A6. `src/Makefile` `clean` deletes two tracked files

`pats_ccomp_gen.hats` and `pats_ccomp_gen_dats.hats` are tracked **and**
listed in `src/.gitignore` (lines 233-234, 286-287, 317-318) **and** removed
by `clean::` (lines 376-377, 409). `AGENTS.md` even documents this as a
known wart ("`make -C src clean` also deletes a few of the tracked ones"). A
tracked file should not be in `.gitignore`.

### A7. `doc/DISTRIB/ATS-Postiats-include/utils/atscc/DATS_C/` is 1.9 MB of checked-in generated C

It contains 2169+ absolute paths of the build machine
(`/home/msorc/install/devel/…`). It is not regenerated by any rule and is out
of sync with `utils/atscc/DATS/` (which now `staload`s `atscc_util.dats`;
the checked-in copy does not). I confirmed the current source regenerates to
the same bytes as the checked-in file *for `atscc_main.dats` only* — the other
two are stale. These are npm-shippable artifacts, so the absolute paths leak
into published packages.

### A8. `doc/DISTRIB/Makefile` is generated from `Makefile.atxt` but both are checked in

`Makefile.gen` regenerates it; the checked-in `Makefile` is byte-identical to
a fresh regeneration (md5 `d86c2f0b40c739d41700957d30771983`, matching
`utils/atsdoc/TEST/genall.md5:160`). Good — but the *mechanism* is fragile:
`Makefile` is derived, so it should be generated in CI rather than committed
and hand-maintained. Note that the intermediates `Makefile_atxt.txt` and
`Makefile_atxt.dats` are also committed in `doc/DISTRIB/`.

### A9. `atspackaging` is not self-contained

It needs `bin/atsdoc` and `bin/patscc` on the path (built by
`Makefile_devl`, not by `atspackaging`), and `atspackaging:: srcget_patsrc_cboot`
requires `src/CBOOT` to have been generated first. Both are documented in
`AGENTS.md` but not enforced by the Makefile — a missing prerequisite
surfaces as a confusing `cp` error.

### A10. 13 `doc/EXAMPLE` directories have a `Makefile` but are not in `doc/Makefile_test`

`ARITH`, `ATSLIB`, `MISC`, `PCPV`, `ATS-DEV-LIST`, `ATS-QA-LIST`,
`EFFECTIVATS/{http-server,linear-streams,MYTEXT,prop-logic,PwTP-bool-vs-prop,Readers-and-Writers}`.

They are therefore never regression-tested. Meanwhile `doc/EXAMPLE/ATSLIB`
*is* shipped in the release tarball (`srcget_doc_example_atslib`), so untested
code is being published.

## B. Documentation: accuracy problems

### B1. `INSTALL` is 11 years stale and describes a build that no longer exists

It says `./configure`, `make all`, `make install`, and clones from
`git://git.code.sf.net`. There is no root `configure`; the build is
`make -f Makefile_devl`. It also references a nonexistent `ATS2-intmin` and
the old `ATS2-Postiats-x.x.x.tgz` naming. Last touched 2015-01-28.

### B2. `doc/DISTRIB/README` still asserts ATS1 is required

Line 4: *"ATS-Anairiats(ATS1) is needed for building ATS-Postiats(ATS2)!"*
This directly contradicts `AGENTS.md` and `src/README`. It is the file a
release engineer reads first.

### B3. `doc/DISTRIB/ATS-Postiats/RELEASE/how-to-release.txt` says of itself

*"The following description is out-of-date."*

### B4. The release notes are in three places and disagree

`CHANGES-ats2` (no 0.4.3), `CHANGES-contrib` (has 0.4.3),
`doc/DISTRIB/ATS-Postiats/RELEASE/*.html` (55 files, through 0.4.2).

### B5. `CHANGES-ats2` header says "(unreleased: branch no-gc)"

The branch is now `master` / `devel`.

### B6. The books teach an API that no longer exists

`ATS2TUTORIAL` chapters `CHAP_LIST`, `CHAP_ARRAYREF`, `CHAP_ARRSZREF`,
`CHAP_MATRIXREF`, `CHAP_MTRXSZREF`, `CHAP_STREAM` document `list`,
`arrayref`, `matrixref`, `stream` and link to
`prelude/SATS/{list,arrayref,matrixref,stream}.sats` — all removed.

The *code* under `ATS2TUTORIAL/CODE/` was migrated to `list_vt` (31
occurrences) but the *prose* in `CHAP_LIST/main.atxt` was not (17 stale
`list(` references). `ATS2FUNCRASH/LECTURE/{05,06,07,10}` still use
`list0`/`stream` (449 references).

The generated `HTML/ATS2TUTORIAL-BOOK-onechunk.html` is dated **2017-06-13**,
nine years older than its sources.

### B7. `doc/EXAMPLE/ATSLIB/prelude_matrixref.dats`

Tests `prelude/matrixref` (removed); its `Makefile.atxt` entry is commented
out, so it is a dead file.

### B8. `doc/EXAMPLE/Java` and `doc/EXAMPLE/OBJC` cannot build

`OBJC` uses `patscc -x objective-c`; `patscc` has no `-x` option (the
`-x`/`ccopt` handling was removed with the other backends — 18 recognized
options, none is `-x`). `Java` needs `contrib/JNI`, which is not in-tree (it
lives in the external `ATS-Postiats-contrib` repo).
`doc/EXAMPLE/JS-emscripten` needs `${PATSHOMERELOC}/contrib/HTML-emscripten`,
also external.

### B9. Many directories have no README

`doc/EXAMPLE/{ARITH,ATSLF,ATSLIB,INTRO,MISC,PCPV,TYPEVAL}`,
`doc/BOOK/{ATS2TUTORIAL,INT2PROGINATS}`,
`contrib/{ats2cpp,atscntrb,CATS-atscc2js,CATS-parsemit,libatscc,libatscc2js}`,
`utils/{atsgrammar,atslex,atsopt,emacs,libatslex,libatsrec,mytempacc}`.

### B10. `README` and `README.md` are near-duplicates with divergent content

`README` has the project-description/license prose, `README.md` adds the
build/development sections and a Travis badge. Neither is copied into the
release tarball — only `AUTHORS`, `COPYING`, `INSTALL`, `VERSION`,
`CHANGES-*` are. So the published tarball has no README and a 2014 INSTALL.

### B11. `NOTES` (root) is a personal scratch file

From 2011-2012 ("for myself to remember some significant features"), unrelated
to the current tree.

### B12. `doc/NOTES/extundelete-2018-03-11.log`

A 103-line `extundelete` recovery log accidentally committed (contains the
author's home paths).

### B13. `doc/BUGS/`

35 bug-repro `.dats` files from 2013-2020 with no README and no test harness.

### B14. `doc/Hibou57/` is empty

One `.keeper` and nothing else. `doc/PROJECT/{MEDIUM,TEMPORARY}` are personal
scratch.

### B15. The `doc/DISTRIB/ATS-Postiats/` skeleton retains removed trees

`libats/ML/` (14 files), `libats/ATS1/`, `libats/ATS2/`, and
`contrib/atscntrb/atscntrb-hx-{getargs,libcurl,libjansson,…}` that the
in-tree `contrib/` no longer has.

### B16. `utils/libatsopt/DATS/patsopt_ext.dats` and `utils/atsdoc/TEST/drv1.dats` are ATS1-era files

Both `staload` the removed `prelude/DATS/list.dats`. `patsopt_ext.dats` is
not built by any current rule (the real one is `src/libatsopt_ext.dats`).

### B17. `CHAP_LIST/main.atxt` and `CHAP_LIST_VT/main.atxt` both exist and both are in `main.db`

The book ships two list chapters, one about a removed type.

### B18. `npm-utils/contrib/Makefile_test` names six directories that do not exist

`atscntrb-libcairo` vs. the actual `atscntrb-hx-libcairo`. The target fails
immediately.

### B19. `npm-utils/contrib/libats-`

The trailing-dash directory name is a rename artifact; `libats-hwxi` is a
symlink into it, and the same name appears in
`doc/DISTRIB/ATS-Postiats-contrib/contrib/libats-` and in
`share/HATS/atspre_define_pkgreloc.hats` (`$PATSCONTRIB/contrib/libats-/hwxi`).

### B20. `src/PORTING.md` is 2843 lines / 416 KB

It is the de-facto architecture document, but `AGENTS.md` (the entry point)
does not link it in its "Other key directories" section.

### B21. `CLAUDE.md` → `AGENTS.md` symlink, and `AGENTS.md`'s first line is `# CLAUDE.md`

Eleven other files refer to "CLAUDE.md" for the no-GC rules. Fine in
practice, but the file is named `AGENTS.md` and titled `CLAUDE.md` — a reader
following `src/README:57` ("see CLAUDE.md") lands on a symlink and may think
the repo is agent-specific.

### B22. `doc/DISTRIB/ATS-Postiats/Makefile` is a symlink to `Makefile_dist`

And `atspacktarzvcf_*` deletes `$(PACKNAME)/Makefile_conf` — a file that no
longer exists.

### B23. `.gitignore` has 487 lines, 72 of which match tracked files

Including `config.h` (the symlink), `ccomp/runtime/pats_ccomp_runtime2_dats.c`,
several `DOCUGEN/Makefile`s, and the whole `ATS2TUTORIAL/HTML/` tree.
Tracking a file while ignoring it is a latent conflict.

### B24. `doc/DISTRIB/ATS-Postiats/RELEASE/` holds 55 historical release-note HTML files

(0.0.1 → 0.4.2), while `CHANGES-ats2` holds the same information in text.
Two release-note formats.

### B25. `doc/EXAMPLE/EFFECTIVATS/README` lists directories that do not exist

`DiningPhil`, `IPC-redis`, `Producer-Consumer`, `word-counting`,
`loop-as-tailrec`, `funcomb-style`.

### B26. `prelude/SATS/CODEGEN/*.atxt` and `prelude/SATS/DOCUGEN/*.atxt` are 25 same-named files with different content

The CODEGEN one generates the `.sats`, the DOCUGEN one generates the HTML.
Confusing naming; `prelude/SATS/CODEGEN/README` says `make -f Makefile_gen`
but the file is `Makefile.gen`.

## C. Structure & hygiene

### C1. Two `contrib` trees with unclear boundaries

In-tree `contrib/` has 10 subtrees (afiber, ats2cpp, atscntrb,
ATS-extsolve×3, CATS-atscc2js, CATS-parsemit, libatscc, libatscc2js). The
`ATS-Postiats-contrib` tarball is built from a *different* external repo
(`github.com/githwxi/ATS-Postiats-contrib`, cloned by `build_release.sh` into
`${PATSCONTRIB}`) whose layout is mirrored by the 46-`.keeper`-only
`doc/DISTRIB/ATS-Postiats-contrib/`.

The `contrib_*.atxt` templates copy from in-tree `../../contrib`, the
`patscontrib_*.atxt` templates copy from `${PATSCONTRIB}` — but one of them
(`patscontrib_HTML-emscripten`) points at `./../../contrib/HTML-emscripten`,
which does not exist in-tree.

### C2. `npm-utils/contrib/` duplicates `contrib/atscntrb/` conceptually

A disjoint package set, plus a third copy under
`npm-utils/contrib/libats-/hwxi`. Three homes for "contributed packages".

### C3. `doc/DISTRIB/ATS-Postiats/` is a checked-in empty skeleton

167 files (152 `.keeper` + 8 real + 55 release notes) that `atspackaging`
fills in-place in the working tree. The build mutates tracked paths and
relies on `.gitignore` to hide the result — 22 of the copied file kinds still
leak (`src/*.spec`, `src/*.c`, `src/README`, `src/mylibies.hats`,
`prelude/*/CODEGEN/*`).

### C4. `src/test/*_out/` is 8.5 GB of build output

Ignored, but the disk cost of `make -C src test` is large.

### C5. `doc/BOOK/ATS2TUTORIAL/HTML/` and `PDF/` are committed build artifacts

1 MB, from 2017, while `.gitignore` in that directory ignores everything
else — inconsistent.

### C6. Root-level stray files in the working tree

`declatext_dats.c`, `htmlgendecl_atxt.dats`, `htmlgendecl_dats.c`,
`ovf{,_3,_5,_6}_dats.c`, `tw_dats.c`, `tz_dats.c` (ignored, but they
pollute `ls`).

### C7. `doc/EXAMPLE/ATS3PORT` is the model to follow

A recent, self-contained corpus with `README`, `MAPPING.txt`, `goldens/`, and
wired into `doc/Makefile_test`. The older trees have none of that.

### C8. `doc/EXAMPLE/ATS-DEV-LIST`, `ATS-QA-LIST`, `doc/BUGS`, `doc/Hibou57`, `doc/PROJECT`

All one-off scratch areas with no README, no harness, no owner.

## D. Recommendations

### D1. Do first (blocking, small)

- [x] **Fix the version skew.** Set `AC_INIT` in
      `doc/DISTRIB/ATS-Postiats/configure.ac` to `0.4.3`; add a `0.4.3`
      section to `CHANGES-ats2`; add
      `doc/DISTRIB/ATS-Postiats/RELEASE/ats2-postiats-0.4.3-release.html`.
      Better: derive all three from `VERSION` in CI so they cannot drift
      again. *(A1, B4)*
- [x] **Delete the `libats/ML` line** from `doc/DISTRIB/Makefile_inclats:46`
      and the 14 `doc/DISTRIB/ATS-Postiats/libats/ML/**` `.keeper` files; the
      `include` tarball then builds. Same for `.gitignore` lines 240-243.
      *(A2, B15)*
- [x] **Resolve `pats_ccomp_gen.hats` / `pats_ccomp_gen_dats.hats`**: remove
      them from `src/.gitignore` (they are tracked), or untrack them and keep
      them generated. Today they are tracked, ignored, and deleted by
      `make clean`. *(A6)*
- [x] **Fix `nix/tarball.nix`**: `atspacktarzvcf` → `atspacktarzvcf_gmp` (or
      `_int`), and give `nix/build.nix` a real `buildPhase`/`installPhase`
      with `src = ../.`. Or delete `nix/{build,default,tarball}.nix` and keep
      only `flake.nix`, which is the one `nix/README.md` and `AGENTS.md`
      reference. *(A3)*
- [x] **Delete `docugen/Makefile_atslib`** (or fix its `libats/ML` reference).
      `codegen/Makefile_atslib` is the live one. *(A4)*
- [x] **Fix `npm-utils/contrib/Makefile_test`** to the real directory names
      (`atscntrb-hx-libcairo`, …). *(B18)*

### D2. Documentation accuracy

- [x] **Rewrite `INSTALL`** for the current flow (`make -f Makefile_devl
      PATSOPT=… all`, `PATSHOME`, the three tarballs), and copy it plus
      `README.md` into the tarball in `srcget_home`. *(B1, B10)*
- [x] **Fix the first line of `doc/DISTRIB/README`** (drop the ATS1 claim)
      and either rewrite or delete
      `doc/DISTRIB/ATS-Postiats/RELEASE/how-to-release.txt`. *(B2, B3)*
- [x] **Decide the fate of the removed-API chapters.** Either port the
      `ATS2TUTORIAL` prose (`CHAP_LIST`, `CHAP_ARRAYREF`, `CHAP_ARRSZREF`,
      `CHAP_MATRIXREF`, `CHAP_MTRXSZREF`, `CHAP_STREAM`) and the
      `ATS2FUNCRASH` lectures to `list_vt`/`stream_vt`/`arrayptr`/`matrixptr`,
      or mark them explicitly "historical (GC-era API)". Right now they read
      as current. Also remove the duplicate `CHAP_LIST` vs `CHAP_LIST_VT` pair
      from `main.db`. *(B6, B17)*
- [x] **Delete or archive** `doc/EXAMPLE/OBJC` and `doc/EXAMPLE/Java` (their
      toolchain is gone), and either add `PATSHOMERELOC` to the
      `JS-emscripten` README or move it under the external-contrib docs.
      *(B8)*
- [x] **Delete** `doc/NOTES/extundelete-2018-03-11.log`, `doc/Hibou57/`,
      `doc/BUGS/` (or give `doc/BUGS/` a README saying it is an archive of
      closed bugs). *(B12, B13, B14)*
- [x] **Add a `README` to each of**: `doc/EXAMPLE/{ARITH,ATSLF,ATSLIB,INTRO,MISC,PCPV,TYPEVAL}`,
      `doc/BOOK/{ATS2TUTORIAL,INT2PROGINATS}`,
      `contrib/{ats2cpp,atscntrb,CATS-atscc2js,CATS-parsemit,libatscc,libatscc2js}`,
      `utils/{atsgrammar,atslex,atsopt,emacs,libatslex,libatsrec,mytempacc}`. *(B9)*
- [x] **Retire `NOTES` (root)** and **`README` (root)** — `README.md`
      supersedes both. *(B10, B11)*

### D3. Build process

- [x] **Add a root `Makefile`** with `all`, `check`, `test`, `doc`, `pack`
      targets that delegate to `Makefile_devl` and `src/Makefile`, so `make`
      works and the entry point is discoverable. Keep `Makefile_devl` as a
      thin include if you want the old name to keep working. *(A5)*
- [x] **Make `doc/Makefile_test` cover all 13 untested example directories** —
      at minimum those that ship (`ATSLIB`, `MISC`, `PCPV`). *(A10)*
- [x] **Stop committing generated C.**
      `doc/DISTRIB/ATS-Postiats-include/utils/{atscc,myatscc}/DATS_C/*.c`
      (1.9 MB, 3000+ absolute build paths) should be generated at package
      time by a `DATS_C` target, exactly as `contrib/ATS-extsolve*/Makefile`
      already does. *(A7)*
- [x] **Generate `doc/DISTRIB/Makefile` in CI** rather than committing it, or
      add a CI check that the committed copy matches a fresh `Makefile.gen`
      run (the md5 already in `genall.md5:160` does this — just wire it into
      the check). *(A8)*
- [x] **Add a `pack` target** that runs `atspackaging` →
      `atspacktarzvcf_{gmp,int}` → `Makefile_inclats tarzvcf` with the
      `bin/atsdoc` and `src/CBOOT` prerequisites declared, so a missing
      prerequisite is a clear error rather than a `cp` failure. *(A9)*

### D4. Structure

- [x] **Give the two `contrib` trees explicit, non-overlapping identities**
      and say so in one place: e.g. "in-tree `contrib/` = packages released
      *with* ATS2; `ATS-Postiats-contrib` = the separate legacy repo,
      packaged separately." Fix `patscontrib_HTML-emscripten.atxt` to use
      `${PATSCONTRIB}` like its siblings. *(C1)*
- [x] **Rename `npm-utils/contrib/libats-` → `libats-hwxi`** (and update the
      two references in `share/HATS/atspre_define_pkgreloc.hats` and
      `doc/DISTRIB/ATS-Postiats-contrib/`), or at minimum document why the
      dash exists. *(B19, C2)*
- [x] **Prune the `doc/DISTRIB/ATS-Postiats/` skeleton** of directories for
      removed trees (`libats/{ML,ATS1,ATS2}`,
      `contrib/atscntrb/atscntrb-hx-{getargs,libcurl,libjansson,…}` that are
      not in-tree), and add the missing `.gitignore` entries for the file
      kinds `atspackaging` copies (`src/*.spec`, `src/*.c`, `src/README`,
      `src/mylibies.hats`, `prelude/*/CODEGEN/*`). *(B15, C3)*
- [x] **Separate "source" from "generated" in `prelude/{SATS,DATS,CATS}`**:
      `CODEGEN/*.atxt` generates the library source, `DOCUGEN/*.atxt`
      generates the HTML. 25 identical basenames with different content is a
      trap. Rename one set (e.g. `CODEGEN` → `SRCGEN`). *(B26)*
- [x] **Untrack the committed build artifacts** in `doc/BOOK/*/HTML/` and
      `PDF/`, or regenerate them in CI and publish them there. *(C5)*
- [x] **Tidy `.gitignore`**: 487 lines with 72 tracked-but-ignored paths.
      Remove entries for files that are tracked, and entries for trees that no
      longer exist. *(B23)*

### D5. Worth doing, cheap

- [x] Add `CONTRIBUTING.md` (build, test, release, doc conventions) —
      `AGENTS.md` covers a lot of this but is presented as a Claude-specific
      file. *(B21)*
- [x] Add a CI job that runs `make -C doc -f Makefile_test testall` over the
      *whole* `doc/EXAMPLE` tree, and one that regenerates
      `doc/DISTRIB/Makefile` and diffs it. *(A8, A10)*
- [x] `doc/EXAMPLE/EFFECTIVATS/README`: delete the list of non-existent
      directories. *(B25)*
- [x] `prelude/*/SRCGEN/README`: `Makefile_gen` → `Makefile.gen`. *(B26)*
- [x] `AGENTS.md` first line `# CLAUDE.md` → `# AGENTS.md`; add
      `src/PORTING.md` to "Other key directories". *(B20, B21)*
- [x] `doc/DISTRIB/Makefile`: drop `$(RMF) $(PACKNAME)/Makefile_conf` (no
      such file). *(B22)*
- [x] Remove the ATS1-era leftovers `utils/libatsopt/DATS/patsopt_ext.dats`
      and `utils/atsdoc/TEST/drv1.dats`, or mark them clearly as ATS1-only
      reference material. *(B16)*

## What was done (2026-10-21)

The recommendations of D1 to D5 have been carried out; the notes below
say what was done and where the outcome differs from the proposal.

### D1

- The version is now checked by `share/SCRIPT/check_release_version.sh`
  (it checks `VERSION`, `configure.ac`, `src/pats_basics.sats`,
  `CHANGES-ats2` and the release notes), and the release notes are
  generated from the changelog by `share/SCRIPT/make_release_notes.sh`
  (so that `CHANGES-ats2` and the release notes cannot disagree). The
  release script calls the check.
- `pats_ccomp_gen.hats` and `pats_ccomp_gen_dats.hats` are tracked and
  are not in `src/.gitignore` any more; `make -C src clean` does not
  delete them.
- `nix/build.nix` builds ATS2 from this tree (it has a real `buildPhase`
  and `installPhase`), `nix/tarball.nix` builds the release tarball
  (`atspacktarzvcf` → `atspacktarzvcf_gmp`), and `nix/default.nix` and
  `nix/shell.nix` use the nixpkgs revision that is pinned in
  `flake.lock` (the broken duplicate of the root, `default.nix`, was
  deleted). `flake.nix` builds this tree now.

### D2

- The chapters that document an API of the GC era carry a note that
  says so (and what to use instead); `CHAP_LIST` (the chapter of the
  removed `list` type, duplicated by `CHAP_LIST_VT`) was deleted and
  removed from `main.db`.
- `doc/EXAMPLE/OBJC` and `doc/EXAMPLE/Java` were deleted (the
  Objective-C backend and the JNI package are not in this tree).
- `doc/BUGS/` was kept and given a README (it is an archive of the bug
  reports).

### D3

- `doc/Makefile_test` covers 10 of the 13 directories that were not
  tested: `ARITH`, `ATSLIB`, `MISC`, `PCPV`, `ATS-DEV-LIST` and the
  `EFFECTIVATS` directories `MYTEXT`, `linear-streams`, `prop-logic`,
  `PwTP-bool-vs-prop` and `Readers-and-Writers`. The two that are left
  out do not build: `ATS-QA-LIST` (the compiler rejects it) and
  `EFFECTIVATS/http-server` (it needs `php`).
- The C code of `patscc` and `myatscc` of the include package is
  generated when the package is built (the `DATS_C` target of
  `doc/DISTRIB/Makefile_inclats`); the checked-in copies (with the
  absolute paths of the machine that had built them) are gone.

### D4

- The two `contrib` trees are described in `contrib/README.md` and in
  `AGENTS.md`.
- The directory `npm-utils/contrib/libats-` is now
  `npm-utils/contrib/libats-hwxi`; the two references to the *external*
  repository (`$PATSCONTRIB/contrib/libats-/hwxi`) keep the old name,
  because that is the name of the directory in that repository (see
  `npm-utils/contrib/README.md`).
- The `CODEGEN` directories (the source of the generated library
  sources) are now `SRCGEN`: in `prelude/{SATS,DATS,DATS/SHARE,CATS}`
  and in the two `CATS` directories of `contrib` and `npm-utils`.

### D5

- The CI is `.github/workflows/ci.yml`: it builds the compiler with the
  current release of ATS2 as the stage-0 compiler, runs the suites
  (`make -C src test`, `make -C utils/atsdoc test`,
  `make -C utils/libatsynmark test`,
  `make -C doc -f Makefile_test testall`), checks the version of the
  release, and regenerates `doc/DISTRIB/Makefile` and the text of the
  documents.
